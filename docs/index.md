# 从这里开始

这是 Live2D 数字角色项目的文档站。四份文档各管一件事，按你手上的活挑一份读：

| 你手上的活 | 去哪 |
|---|---|
| 想把它跑起来，或者卡住了 | [操作手册](runbook.md) |
| 要改代码，查签名、字段、错误码 | [接口参考](reference.md) |
| 要搞懂一次对话怎么走、谁拥有什么 | [架构与时序](architecture.md) |
| 想知道为什么这么设计、代价是什么 | [技术决策](decisions.md) |

接口参考由 `src/` 的 docstring 生成，页面内容与代码同源；其余三份是手写的。

## 一句话说清这个项目

你打字 → 大模型流式回复 → 语音合成 → Live2D 角色开口说话、带表情。

主进程负责"想和说"，渲染子进程负责"演"，两边只通过两条队列传普通字典。
